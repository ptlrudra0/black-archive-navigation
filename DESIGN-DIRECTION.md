# SIH26168 | The Black Archive | design direction, 29 September 2026
Project: independent GNSS+INS navigation experiment and SIH pitch site. Audience: technical judges and teammates. Action: inspect the outage experiment and its real-data method. Emotion: confidence, focus, curiosity, scientific honesty.

References, deconstructed (not copied): SpaceX https://www.spacex.com/ gives the full-bleed single-object hero, severe black/white hierarchy, minimal masthead and huge margins; Linear https://linear.app/now/how-we-redesigned-the-linear-ui shows reduced navigation noise and precise alignment; Mapbox Navigation Night https://docs.mapbox.com/map-styles/reference/navigation-night/ demonstrates bright path and labels on a subdued dark map; Awwwards space-map reference https://www.awwwards.com/inspiration/space-map-navigation-simone-3d-space-experience offers a continuous path motif; Godly map https://godly.website/website/map-427 supplies editorial map composition. Secondary: KITTI raw data https://www.cvlibs.net/datasets/kitti/raw_data.php for scientifically credible route/evaluation provenance. No external artwork copied. Original route glyph and terrain/contour study will be SVG/CSS, keeping the single-focal-object rule.

Selected direction: orbital cartography, not cockpit sci-fi. Pure #000 canvas (60%), near-black #101116 utility surfaces and off-white typography (30%), #aab9ed periwinkle reserved for active trajectory/CTA (10%). Space Grotesk display + IBM Plex Mono readouts, Google Fonts. Editorial 12-column grid, max 1440, margins clamp(24px,4vw,72px), 24px gutters. Golden 5:8 split for statement versus route graphic at desktop. Type scale 12/14/18/28/48/76/122; spacing 8/16/24/40/64/104/168. Black whitespace as the second shape. Hairlines only where needed for scientific axes; no card grids. One pill nav, 52px height, sliding active state. Buttons radius 999px, editorial panels 6px, glow only below accent CTA. No shadows on content.

Architecture: Home (route as full-viewport hero, one statement), Lab (interactive path and outage scrubber as hero; truth, raw GNSS and estimated outputs), Evidence (single errors plot, metrics and clear benchmark protocol), System (one ESKF diagram, implementation/limitations). A static public site can demonstrate precomputed real-data runs but cannot host Python itself. Python backend API remains independently runnable; no false claim of a live hosted backend. If feasible, host separately.

Motion: intro route draws once in 700ms; nav indicator 420ms cubic-bezier(.22,1,.36,1); route slider updates immediately; hover/press 180ms; reveal only on first entry. Reduced-motion removes transitions. Desktop 1440/1280: two-column hero; tablet 820: compressed typography with route dominant; phone 390/360: stacked copy then full-width route, accessible 44px controls, swipe-free essentials. Semantic landmarks, strong text contrast, focus ring, no inaccessible canvas-only data, no animation-dependent meaning. Lightweight SVG, no raster asset downloads or third-party runtime maps; font fallback. QA at 1440/820/390, screenshot actual public pixels, inspect overflow, truth labels, controls, and route data.
