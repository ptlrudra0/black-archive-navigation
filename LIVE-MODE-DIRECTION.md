Live route mode art direction and limits, 30 Sep 2026.
User wants a mobile navigation start action, on a bus. Fit the existing Black Archive brand and Apple Maps' map-first hierarchy: a full-viewport dark geographic map, one floating position puck, top condensed status, bottom large simple start/stop control and two-line reliability summary. No multi-card dashboard. One accent periwinkle; pure black controls. Current browser map is a positioning experiment, not turn-by-turn navigation, route planning, or an offline map. Do not present a vehicle route or fake roads.
Sensor contract: user clicks Start; iOS motion/orientation permission requested synchronously within that gesture; geolocation separately requested. On real GPS fixes, show raw device-reported horizontal accuracy, speed (if supplied) and position. During stale fixes, propagate an estimated point only if credible recent GPS speed and heading and valid orientation changes exist; model elapsed time, uncertain drift, and never claim measured error without ground truth. Raw freehand acceleration cannot be integrated reliably into absolute bus position: unknown phone mount/orientation and gravity bias. If no valid speed/heading, freeze last fix and label waiting for GPS, not pretend dead reckoning. Distinct map puck visual/state for GPS fresh vs estimated vs stale. Handle background pause, permission denial, no support, motion event missing, lack of heading, and high-accuracy timeout. Never upload user coordinates: all browser-local; no retention. Use public tiles with attribution and respect provider policy. Reduced motion and accessible large touch targets.
