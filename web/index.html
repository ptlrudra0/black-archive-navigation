*READ THIS FIRST

This is a bounded experiment, not a validated navigation system. The KITTI OXTS reference is itself GPS/INS-derived, not independent surveyed ground truth. Acceleration, yaw rate, forward speed and the reference positions come from that same stream. Position measurements were downsampled to 1 Hz and withheld from 5 to 11 seconds. These errors do not establish field accuracy, real GNSS-outage performance or an ML model.

REPRODUCIBLE PIPELINE

Open Python code processes the real KITTI OXTS logs offline. This public page visualizes its exported trace. It is not connected to a live receiver or a hosted backend.

01 / READ

Sensor stream

Use timestamped forward acceleration and yaw rate from the 2011 KITTI OXTS drive. Convert latitude and longitude to a local metric frame for comparison.

02 / PREDICT

Inertial continuation

Propagate position, speed and heading between fixes. Carry covariance and two bias terms in a six-state Kalman filter.

03 / CORRECT

Position returns

Fuse a 1 Hz position and forward-speed observation when available. Deny position updates for six seconds; then resume corrections.

04 / VERIFY

Measure, don't promise

Compute per-frame Euclidean error and outage-window RMSE. A stronger future test needs an independent ground-truth receiver, longer sequences, honest holdout and a full 3D error-state filter.
