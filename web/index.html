*READ THIS FIRST

This is a bounded experiment, not a validated navigation system. The KITTI OXTS reference is itself GPS/INS-derived, not independent surveyed ground truth. Acceleration, yaw rate, forward speed and the reference positions come from that same stream. Position measurements were downsampled to 1 Hz and withheld from 5 to 11 seconds. These errors do not establish field accuracy or real GNSS-outage performance. The separate learned correction experiment below uses different data and a different paired baseline.

Outage-window position RMSE over 70 six-second test windows (3,990 prediction instants). Paired open-loop baseline vs ridge correction, each test on a drive excluded from its training. This is not directly comparable to the 1.371 m Kalman result above, which used a different one-clip test and initial conditions.

BOUNDARIES

The route above is an illustration, not the measured trajectory. KITTI OXTS is GPS/INS-derived and not independent surveyed truth. The experiment hides position updates artificially, uses a vehicle-mounted OXTS stream and does not show real satellite loss or performance on a handheld phone. The phone sensor lab uses a separate GNSS/inertial filter and session bias learning, not this trained vehicle model.

04 / INSTRUMENT

What carries
the route.

REPRODUCIBLE PIPELINE

Open Python code processes the real KITTI OXTS logs offline. This public page visualizes its exported trace. It is not connected to a live receiver or a hosted backend.

01 / READ

Sensor stream

Use timestamped forward acceleration and yaw rate from the 2011 KITTI OXTS drive. Convert latitude and longitude to a local metric frame for comparison.

02 / PREDICT

Inertial continuation

Propagate position, speed and heading between fixes. Carry covariance and two bias terms in a six-state Kalman filter.

03 / CORRECT

Position returns

Fuse a 1 Hz position and forward-speed observation when available. Deny position updates for six seconds; then resume corrections.

04 / LEARN

Held-out drive correction

A ridge model trained on other KITTI drives predicts position drift from the inertial stream. A nested drive-held-out test selects its regularization and compares corrected positions to paired open-loop propagation. This model is offline vehicle research; the phone tracker has its own session bias learner.

05 / VERIFY

Measure, don't promise

Compute per-frame Euclidean error and outage-window RMSE. The separate learned model is validated by held-out drive. A stronger future test needs independent ground truth, real outages, broader conditions and a full 3D error-state filter.
